Mathematical Pipeline

How the Colorization Pipeline Works

Rather than predicting 3-channel RGB directly, the model decouples brightness from color using the CIE Lab color space, reducing the task to a 2-channel regression problem.

STEP 01

Preprocessing & Resizing

The input image is uniformly resized to $256 \times 256$ pixels using bilinear interpolation and normalized to floating-point $[0.0, 1.0]$.

STEP 02

CIE Lab Representation

The RGB tensor is transformed into the CIE Lab space. The $L^*$ channel represents lightness $[0, 100]$ and is normalized to $[-1, 1]$ to serve as the single-channel input tensor.

STEP 03

U-Net Feature Learning

A 6-stage encoder progressively downsamples the spatial resolution from $256 \times 256$ down to a $4 \times 4$ bottleneck, extracting high-level semantic context.

STEP 04

Skip Connections & Decoding

ConvTranspose2d layers upsample features while concatenating encoder skip connections, preserving edge sharpness and fine structural boundaries.

STEP 05

RGB Reconstruction

The predicted $a^*$ and $b^*$ channels are scaled by 128, concatenated with the denormalized $L^*$ channel, and converted back to the sRGB gamut with $[0.0, 1.0]$ clipping.

Academic Project

College Mini Project Overview

Created for the Neural Networks and Deep Learning course (AM722T2A).

Project Title

Deep Image Colorization Using U-Net in CIE Lab Color Space

The objective of this project is to develop an automated image colorization pipeline that accepts a monochrome or grayscale input and predicts plausible chromatic information. By separating luminance from chrominance, the neural network learns high-level semantic priors (such as trees being green, skies being blue, and roads being gray) rather than learning redundant illumination physics.

The system is implemented in PyTorch, trained on diverse scenes from the ADE20K dataset, and presented with a modern frontend integration designed specifically for academic demonstration.
